## List of challenge KPIs and how the project addressed them

The challenge asked for product concepts to realize novel applications of the Cardano blockchain.

We have created an extensive workshop series around ESP32 microcontrollers that teach the basics of how to program and use microcontrollers and how to integrate them with the Cardano blockchain as well as rudimentary examples of how to create your own API or web frontends on ESP32 microcontrollers. While these workshop use cases are educational only, we teach the basics of Cardano in the process in the hopes to attract IoT builders from the ESP32/Arduino community around the world to build real world applications on Cardano and bring the blockchain into the physical world. We teach everything Cardano from installing and funding a wallet for use on the Preprod testnet to introductions to various Cardano ecosystem libraries, APIs and companies such as Koios, Mesh, Blockfrost, MinSwap, Cexplorer, CardanoScan, etc.

While we can't cover everything, we hope to inspire users to take this as the starting point of their journey into Cardano and the world of IoT to see new, more diverse and advanced uses cases coming to life in the future.

## List of project KPIs and how the project addressed them

### Build a platform for either Cardano users that are interested in IoT devices and how to bring those two together - or IoT builders, that want to integrate Cardano into their projects

- We have created a series of 5 workshops, which will introduce the user to Cardano, Arduino microcontrollers and how to use Cardano related APIs or even build their own APIs based on NodeJS or directly on their microcontroller
- All workshops are based on each other, so we go from the very basics to more advanced examples teaching the fundamentals of reading, writing and updating physical hardware or sensors on ESP32 microcontrollers or read or submit transactions on the Cardano blockchain
- To accompany all this, we have created a list of dedicated hardware, where to get it and how to set it up as well as a comprehensive glossary to explain terms used on Cardano, blockchain or the world of IoT, Arduino and microcontrollers

### Teach Cardano in the process

- We introduce users to the Cardano ecosystem, its wallets, libraries, APIs or blockchain explorers

- The user learns about Cardano in general, how to read, build or submit transactions and how to build their own APIs for minting NFTs or putting data on chain.

- While we aimed to only use free services throughout the workshops to keep initial  costs and the general barrier to entry low for all users, we are introducing the users to various paid services on Cardano from NMKR over Blockfrost, Maestro, TapTools, jpgStore and others - so when they finally build something for production, they already know where to go.

## Key achievements (in particular around collaboration and engagement)

- Fully functioning web-app / platform around Cardano and IoT devices
- Workshop Series of 5 Workshops including multiple various tech stacks from Arduino, NodeJS, REST APIs, physical integrations of sensors, displays and other IoT hardware like ESP32 controller
- Comprehensive Building Blocks for main use cases like making API calls to a Cardano API like Koios from an ESP32 Microcontroller, setting up the hardware, etc.
- Short introductions to Cardano, Arduino, NodeJS and all the tech used on CardanoThings.io
- Glossary around blockchain & IoT
- Curated resources for each workshop to send the user on further building adventures
- Teaching the basics of Cardano including the CIP process
- Providing a hands-on-workshop for CIP13 Payment links and what could be done with it (when finally implemented in wallets)

## Key learnings

- While creating this workshop series and testing it with students, we found that we might have to restructure the original workshop series into more comprehensive shorter lessons. We cover too many different tech stacks and loose people in the process.
- That being said, we have already started a new section called "Building blocks" which will cater to a wider audience, which may already know a lot of the things we teach during the workshops. These building blocks are single use-case code examples which enable users to learn about one thing and one thing only, so they can go on building their own products and ideas
- We learned that even with out 18 months delay of delivering this Cardano still has not implemented CIP13 payment links in most mobile wallets
- Personally we learned a lot about the Project Catalyst process and how to navigate it. In hindsight, smaller but more milestones would have been the way to go - also more thorough research before even submitting a proposal just to find out afterwards that Cardano isn't even able to do the things we wanted people to teach about.

## Next steps for the product or service developed

We will seek connections throughout the IoT community as well as the Cardano community to build and gather more examples of real world uses cases for physical integrations of Cardano with IoT tech like ESP microcontrollers. While the created workshop series is aimed at curious beginners, it is time to target a more advanced group of developers and so we will add building blocks and examples for PlatformIO and Rust integrations. All of this depends on further funding, so we will explore partnerships and revenue avenues to fund the further development of this platform.

If the platform gains traction, we may to seek further funding for a series of Youtube videos and other features.

## Final thoughts/comments

While this has been fun, it has also been frustrating to see how the Cardano ecosystem lacks very basic functionality such as scanable QR-Codes for transactions and so for now, our Workshop Five remains mostly theoretical. We hope the Cardano ecosystem will maybe take note of the presented use case, see the value and advance to a level where user-friendly payment links via QR-Codes can lead to very real, very physical use cases far beyond than just sending ADA around a blockchain.
